# Bubble Sort Algorithm with Graph

 Overview
This project demonstrates the **Bubble Sort algorithm** using:
- **C++** for sorting implementation
- **Python (Matplotlib)** for plotting time complexity graph

Bubble Sort is a simple comparison-based sorting algorithm where adjacent elements are compared and swapped if they are in the wrong order.

---

 Algorithm: Bubble Sort
1. Start from the first element
2. Compare adjacent elements
3. Swap if the first is greater than the second
4. Repeat the process for all elements
5. After each pass, the largest element moves to the end

---

 Time Complexity
- **Best Case:** O(n) (already sorted, optimized)
- **Average Case:** O(n²)
- **Worst Case:** O(n²)
