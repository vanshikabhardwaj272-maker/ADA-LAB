# Linear Search Algorithm with Graph

## 📌 Overview
This project demonstrates the **Linear Search algorithm** using:
- **C++** for implementation
- **Python (Matplotlib)** for plotting the time complexity graph

Linear Search is a simple searching technique that checks each element in a list sequentially until the desired element is found or the list ends.

---

## 🧠 Algorithm: Linear Search
1. Start from the first element of the array
2. Compare each element with the key
3. If a match is found, return the index
4. If the end is reached, the element is not present

---

## ⏱ Time Complexity
- **Best Case:** O(1) (element found at first position)
- **Average Case:** O(n)
- **Worst Case:** O(n) (element found at last position or not found)
