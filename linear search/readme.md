# Linear Search Algorithm with Graph

 Overview
This project demonstrates the **Linear Search algorithm** using:
- **C++** for implementation
- **Python (Matplotlib)** for plotting the time complexity graph

Linear Search is the simplest searching technique where elements are checked one by one until the target element is found.

---

Algorithm: Linear Search
1. Start from the first element
2. Compare each element with the key
3. If match is found, return index
4. If end of array is reached, element is not present

---

 Time Complexity
- **Best Case:** O(1)
- **Average Case:** O(n)
- **Worst Case:** O(n)
